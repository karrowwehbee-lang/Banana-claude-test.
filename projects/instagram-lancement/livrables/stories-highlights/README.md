## How to publish

1. Post the Stories of one folder, in order (they disappear from your story after 24 h, the Highlight keeps them).
2. On each Story: Highlight ▸ choose or create the Highlight (About, Projects, Materials, Services, Process, Contact).
3. Edit the Highlight ▸ Edit cover ▸ choose `_cover.png` from the same folder.
4. Contact, Story 04: before posting, add a « Message » or « Link » sticker on the « Send a message » button.
