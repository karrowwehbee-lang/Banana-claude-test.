# Chambre — aménagement KAÏRA à partir du modèle Blender du client

Architecture et matériaux conservés : marbre vert central, colonnes chêne (haut plein, bas cannelé, LED),
panneaux muraux blancs, chevets chêne, parquet chêne, façades blanches du mur droit.

Ajouts : tête de lit flottante (bouclé crème, cadre chêne, filet laiton), lit 180 × 200 sur sommier
tapissé, banc velours sauge, plafond architectural (faux plafond périphérique 2,60 m, caisson 2,80 m
avec gorges LED 2700 K, lames chêne dans l'axe du marbre), suspensions opalines de chevet, rasants
sur le marbre.
